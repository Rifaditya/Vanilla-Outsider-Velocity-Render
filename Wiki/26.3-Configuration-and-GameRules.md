## 2. Step-by-Step Player Workflow & Command Usage

### 1. Checking Real-Time Telemetry (`/velocityrender status`)
Players can check their instantaneous velocity, server tick performance, active tickets, and chunk mesh state at any time:

```
/velocityrender status
```

**Example Output**:
```

 §7• §fYour Velocity: §a1.45 b/t (29.0 m/s)§r

```

### 2. Querying Active GameRules (`/velocityrender get <rule>`)
```
/velocityrender get lead_multiplier
-> §6velocityrender:forward_lead_multiplier = §e100%

/velocityrender get min_speed
-> §6velocityrender:min_speed = §e0.2 b/t
```

### 3. Modifying Settings in Real Time (`/velocityrender set <rule> <value>`)
Operators can tune settings on the fly without restarting the server or client:
```
/velocityrender set lead_multiplier 150
-> §aUpdated velocityrender:lead_multiplier to 150

/velocityrender set min_speed 30
-> §aUpdated velocityrender:min_speed to 30
```

### 4. Restoring Defaults & Reloading
```
/velocityrender reset
-> §aReset all You Run Fast settings to vanilla defaults.

/velocityrender reload
-> §aReloaded You Run Fast configuration successfully.
```

## 3. Mathematical Conversions & Configuration Ranges

- **Forward Lead Multiplier**:
  $$\text{Multiplier Ratio} = \frac{\text{Setting Value}}{100.0}, \quad \text{Range: }[0, 300]\%$$
  - `100` = 1.0x baseline lookahead ($16$ blocks per block/tick).
  - `200` = 2.0x aggressive lookahead ($32$ blocks per block/tick).
  - `0` = Disables forward bias entirely.
- **Minimum Speed Threshold**:
  $$\text{Velocity Threshold} = \frac{\text{Setting Value}}{100.0}\text{ blocks/tick}, \quad \text{Range: }[1, 200]$$
  - `20` = $0.20\text{ b/t} = 4.0\text{ m/s}$ (Default: activates on sprint/horse).
  - `50` = $0.50\text{ b/t} = 10.0\text{ m/s}$ (Activates only on Elytra / Ice Boat).

## 5. SNBT & Level.dat GameRule Schema

Settings are saved automatically in Minecraft's `level.dat` under `GameRules`:

```snbt
{
    GameRules: {
        "velocityrender:enabled": "true",
        "velocityrender:forward_lead_multiplier": "100",
        "velocityrender:budget_conservation": "true",
        "velocityrender:min_speed_threshold_pct": "20",
        "velocityrender:debug_mode": "false"
    }
}
```
